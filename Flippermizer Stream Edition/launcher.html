Open the Overlay, Bestiary, and Archipelago Options from one launcher, with the Base Game APWorld bundled alongside the app for easier setup on a fresh machine.

What is Flippermizer?

Flippermizer is a pinball randomizer and Archipelago setup that turns curated VPX table worlds into a connected progression run with checks, traps, boss fights, hints, and end-of-run stats.
