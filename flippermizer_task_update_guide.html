Task Update Guide

Base examples for merging task repository edits into the current task list. The AC/DC seed below has already been written as grouped suggestions, so duplicate placements can be updated from one canonical edit.

Edit Types

full_rewrite
Use when the task is valid but the title or tooltip needs to be rewritten from the guide into direct player instructions.
task_impossible
Use when the original objective should not be attempted as written. Provide a replacement task and a replacement_reason.
grouped duplicate
Use the repository editor's GROUPS tab, or one grouped suggestion with an ids array, when the same table task appears in multiple difficulties or placements.
template table
When a table has polished task titles and direct How to Achieve tooltips, mark it as a template table in the repository so it can guide future rewrites.
current task merge
Write accepted title/type/tooltip updates back to generic_check_pools.json, then rebuild flippermizer_task_repository_data.js.

AC/DC Seed Groups

Start Any Multiball
full_rewrite3 placementsmultiball start
Grouped ids
Easy 0, Medium 3, Hard 5
How to Achieve
Qualify any main multiball: Jam by shooting 6 ramps, Album by completing 3 target banks, or Tour by shooting 8 loops. When a multiball insert flashes, shoot the right ramp to start it.
Spell F-I-R-E Once
full_rewrite2 placementslane spelling
Grouped ids
Easy 2, Medium 4
How to Achieve
Roll through the unlit FIRE inlane/outlane letters, using flipper lane-change to rotate the lit lanes if needed. One full FIRE completion satisfies this task and builds toward relighting Song Jackpot.
Start 2x Playfield
full_rewrite3 placementsplayfield multiplier
Grouped ids
Easy 3, Medium 0, Hard 3
How to Achieve
Hit the bell 3 times to start 2X playfield scoring for 20 seconds. Additional bell hits while 2X is active reset the timer.
Collect a Song Jackpot
full_rewrite3 placementscannon collect
Grouped ids
Easy 4, Medium 2, Hard 4
How to Achieve
The Song Jackpot is lit at game start; otherwise complete FIRE 3 times to relight it. Shoot the right ramp to load the Cannon, then fire at the center AC/DC target.
Start 3x Playfield
full_rewrite3 placementsplayfield multiplier
Grouped ids
Easy 5, Medium 5, Hard 0
How to Achieve
Hit the bell 3 times to start 2X, then hit the bell 3 more times before 2X expires to start 3X playfield for 20 seconds. Bell hits during 3X reset the timer.
Start a Multiball and Collect a Jackpot
full_rewrite1 placementmultiball jackpot
Grouped ids
Hard 2
How to Achieve
Qualify and start any main multiball, then shoot any lit jackpot shot before the multiball ends. Jam, Album, or Tour Multiball all satisfy the start requirement.
